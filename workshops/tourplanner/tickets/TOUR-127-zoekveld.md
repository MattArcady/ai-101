# TOUR-127 — Zoekveld wist niet met Escape

| | |
| --- | --- |
| **Status** | Backlog |
| **Type** | Bug |
| **Prioriteit** | Laag |

`<input type="search">`, maar niet in alle browsers gelijk.

Niet urgent — er staat een kruisje in het veld dat wél werkt.
